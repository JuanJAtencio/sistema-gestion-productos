# 🛒 Sistema de Gestión de Productos — Python

Aplicación de consola desarrollada en Python que permite gestionar productos mediante operaciones CRUD (Crear, Leer, Actualizar y Eliminar).

Este sistema simula un inventario utilizando estructuras de datos en memoria y un menú interactivo en terminal con colores.

---

## 🚀 Funcionalidades

✅ Registrar productos
✅ Listar productos
✅ Buscar producto por ID
✅ Actualizar productos
✅ Eliminar productos
✅ Reporte de stock bajo configurable
✅ Interfaz en consola con colores

---

## 🛠️ Tecnologías utilizadas

* Python 3
* Colorama

---

## 📦 Instalación

Clonar repositorio:

```bash
git clone https://github.com/JuanJAtencio/sistema-gestion-productos.git
```

Instalar dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar programa:

```bash
python main.py
```
